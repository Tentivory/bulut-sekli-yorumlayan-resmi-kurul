# T.C. Bulut Şekli Yorumlama Kurulu

## Resmi Referans Yazılımı

Bu depo, Türkiye Cumhuriyeti **Bulut Şekli Yorumlama Kurulu**'nun tek ve resmi referans uygulamasıdır.

Kurul 1923'ten beri gökyüzüne bakmakta, fakat tutanakları ancak 2026'da dijitalleştirilmiştir. Gecikmenin sebebi evrakların rüzgarda uçmasıdır.

Bu yazılım **ciddi bir bilimsel araçtır**. Gülmeyiniz. Gülerseniz kurul dağılır.

## Ne Yapar?

- Gökyüzünde gördüğünüz şekli resmi dile çevirir.
- Oybirliği varmış gibi karar yazar.
- Çay molasını bilimsel süreç olarak tanımlar.
- Temyiz hakkını tanımaz; çünkü bulut kaçmıştır.

## Kuruluş

Python 3 yeterlidir. Bağımlılık yoktur. Kuruluş da resmiyet kadar sadedir:

```bash
python3 kurul.py
```

Kendi gözleminizi iletmek isterseniz:

```bash
python3 kurul.py "soldaki o şey bir balina mı"
```

## Örnek Tutanak

Program her çalıştırıldığında yeni bir resmi tutanak üretir. Tutanaklar birbirini tutmak zorunda değildir. Doğa da tutmaz.

## Hukuki Uyarı

- Bu kararlar bağlayıcıdır.
- Bağlayıcılık yalnızca duygusaldır.
- Kurulu eleştirmek, bulutu eleştirmektir.
- Bulutu eleştirmek mümkün değildir çünkü o artık başka şekildedir.
